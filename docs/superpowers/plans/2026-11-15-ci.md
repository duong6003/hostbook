# CI Efficiency and Coverage Implementation Plan

> Execute inline under superpowers:executing-plans; independent review is assigned separately.

**Goal:** Reduce repeated Windows downloads while retaining lifecycle checks and make platform coverage visible.
**Architecture:** An opt-in runner cache stores only archives under their expected SHA256; the installer verifies every reuse. GitHub Actions restores only this directory and retains separate PR and main runs.
**Tech Stack:** PowerShell, Bash, GitHub Actions.
**Spec:** docs/design/ui-migration.md; docs/superpowers/plans/2026-11-15-delivery.md.

## Constraints and review focus

- Never cache installation, test results, host data or credentials. Keep installs fresh and checksum every hit.
- Failed or corrupted downloads must never be extracted. Preserve version, OS and architecture identity.
- PR and main checks must run; unrelated refs and event types must not cancel each other.
- Report cold/warm timings as observed, including cache restore/save, without inventing results.
- Use isolated fixtures; preserve Windows lifecycle and native checks.
