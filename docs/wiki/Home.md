# hostbook user guide

hostbook manages SSH hosts in your terminal. It combines fuzzy search, reusable
credentials, tmux sessions, and Git-based synchronization while keeping hosts in
standard OpenSSH configuration.

The app interface is currently in Vietnamese. These guides use English explanations
and include exact Vietnamese menu labels where needed.

| Guide | Start here when you want to... |
| --- | --- |
| [Getting started](Getting-started) | Install hostbook, create your host list, or connect another machine. |
| [Daily use](Daily-use) | Search, connect, manage hosts, open groups, and transfer files. |
| [Sync and sharing](Sync-and-sharing) | Choose a Git remote, resolve conflicts, or share hosts. |
| [Secrets and security](Secrets-and-security) | Manage keys, passwords, unlocking, and recovery. |
| [Appearance](Appearance) | Change layouts, colors, icons, and terminal backgrounds. |
| [Troubleshooting](Troubleshooting) | Diagnose installation, connection, or sync problems. |
| [Development](Development) | Understand the codebase and run checks. |
