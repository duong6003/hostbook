# hostbook user guide

hostbook manages SSH hosts in your terminal. It combines fuzzy search, reusable
credentials, tmux sessions, and Git-based synchronization while keeping hosts in
standard OpenSSH configuration.

The interface is available in English and Vietnamese (see [Appearance](Appearance)).
These guides quote the English labels and give the Vietnamese label in parentheses
where it helps.

| Guide | Start here when you want to... |
| --- | --- |
| [Getting started](Getting-started) | Install hostbook from the private repository, walk through first run, or connect another machine. |
| [Daily use](Daily-use) | Search, connect, manage hosts, open groups, and transfer files. |
| [Sync and sharing](Sync-and-sharing) | Choose a Git remote, resolve conflicts, share hosts, or import a package. |
| [Secrets and security](Secrets-and-security) | Manage the vault, keys, passwords, unlocking, and recovery. |
| [Appearance](Appearance) | Change layouts, colors, icons, language, and terminal backgrounds. |
| [Troubleshooting](Troubleshooting) | Diagnose installation, connection, or sync problems. |
| [Development](Development) | Understand the codebase and run checks. |
